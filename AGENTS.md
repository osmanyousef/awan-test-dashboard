# Awan Booking Dashboard — Agent Instructions

Vue 3 (`<script setup lang="ts">`) + Vue Router + Vite 8 + Tailwind CSS v4. Bilingual (English/Arabic, RTL).

Read these before any frontend work:

- `.agents/rules/frontend-standards.md`: architecture, CSS/JS rules, priorities, and which skill to load for which task
- `.agents/rules/mockup-workflow.md`: two-phase flow for implementing mockups
- `.agents/skills/awan-design-system/SKILL.md`: tokens, contrast, component standards
- `design-map.md`: token and component registry (keep it updated)

Project skills live in `.agents/skills/`. Vendored third-party skills and their pinned versions are listed in
`.agents/skills-sources.md`.

Verify every change with `npm run build`.
